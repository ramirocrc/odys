# `odys.parameters.context`

Internal implementation detail. Most users do not need this page directly.

`ModelContext` is the shared indexing of one problem: the time and scenario coordinates, the step length, the scenario probabilities, and scenario profiles as arrays. Entity coordinates belong to the formulations. It is the only producer of time labels, which are strings.

::: odys.parameters.context
