# `odys.optimization.formulations`

Model formulations, one per entity type. A `Formulation` owns, for every entity of its type: the parameter arrays, the decision variables, the constraints, the net power it injects into the power balance and its profit per scenario. `FORMULATIONS` lists every entity type's formulation, in build and power-balance order.

## Modules

- `base`
- `charging`
- `electric_vehicle`
- `energy_market`
- `fixed_load`
- `flexible_load`
- `generator`
- `stationary_storage`
- `storage`

::: odys.optimization.formulations
