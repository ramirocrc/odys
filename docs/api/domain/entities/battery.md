# `odys.domain.entities.battery`

Battery value object: capacity, power limits, charging/discharging efficiency, state-of-charge bounds, self-discharge, and degradation cost. Owned by `StationaryStorage` and `ElectricVehicle`.

See [StationaryStorage](../../../user_guide/storage.md) in the User Guide.
