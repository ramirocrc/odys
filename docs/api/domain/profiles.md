# `odys.domain.profiles`

Typed time-series profiles. Each profile references the entity it belongs to: `LoadProfile` a load, `AvailableCapacityProfile` a generator, and `PriceProfile` a market.

See [Scenario](../../user_guide/scenario.md#profiles) in the User Guide.
