# `odys.solvers.outcome`

What a solver run returns. `SolveStatus` is public (`result.solver_status`); `SolveOutcome` is internal: the solver returns it and `OptimalDispatchResults` is built from it.

See [Results](../../user_guide/optimization/results.md#solver-status) in the User Guide for reading the status of a run.

::: odys.solvers.outcome
