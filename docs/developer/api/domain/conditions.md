# `odys.domain.conditions`

Initial and final conditions of a run. Each condition references the asset it belongs to: `GeneratorInitialState` and `GeneratorFinalState` a generator, `StorageInitialState` and `StorageFinalState` a stationary storage, and `ElectricVehicleInitialState` and `ElectricVehicleFinalState` an electric vehicle.

See [Initial and final conditions](../../../user_guide/model/first_model.md#initial-and-final-conditions) in the User Guide.

::: odys.domain.conditions
