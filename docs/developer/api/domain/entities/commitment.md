# `odys.domain.entities.commitment`

Commitment value object: how an asset is switched on and off, with minimum up and down times and start-up and shut-down costs. Owned by `Generator` and, when it can switch off, `FlexibleLoad`.

See [Minimum up and down time](../../../../user_guide/assets/generator.md#minimum-up-and-down-time) and [Switching on and off](../../../../user_guide/assets/flexible_load.md#switching-on-and-off) in the User Guide.

::: odys.domain.entities.commitment
