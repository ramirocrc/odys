# `odys.optimization.formulations.storage`

The shared battery model of battery storage and electric vehicles (`StorageFormulation`), a reusable part both formulations compose. Variable and constraint names carry the entity dimension as a prefix.

The variables, constraints and objective terms are written out on the [Batteries](../../../../formulation/batteries.md) formulation page.

See also [Battery](../../domain/entities/battery.md) for the domain model and [entity_arrays](../../parameters/entity_arrays.md) for the parameter arrays.

::: odys.optimization.formulations.storage
