# `odys.optimization.formulations.stationary_storage`

The stationary storage formulation: the shared battery model (see [storage](storage.md)), injecting discharge minus charge into the power balance, with its degradation cost in the profit.

The variables, constraints and objective terms are written out on the [Batteries](../../../../formulation/batteries.md) formulation page.

See also [StationaryStorage](../../domain/entities/stationary_storage.md) for the domain model and [entity_arrays](../../parameters/entity_arrays.md) for the parameter arrays.
