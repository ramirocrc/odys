# `odys.optimization`

Optimization internals: the formulations, objective terms and constraints that build the linopy model, and each formulation's results view.

Most users do not need these pages directly. They are useful if you are extending the model builder or debugging constraints. Parameters live in `odys.parameters` and solving in `odys.solvers`.
