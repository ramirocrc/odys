Features

Formulation and tooling.

Stochastic and risk-averse objectives

Maximize expected profit over the scenarios, or add a CVaR term to weight the tail. Results from the Day-Ahead or Intraday example.

    Solver-agnostic

    HiGHS is installed by default. Gurobi, CPLEX and SCIP are optional extras.

    HiGHSGurobiCPLEXSCIP
    config = SolverConfig(
    solver_name=SolverName.GUROBI,
)
system.optimize(config)

    Input validation

    Assets, profiles and scenarios are Pydantic models, validated before the model is built.

    >>> Generator(
...     name="gas",
...     nominal_power=-50.0,
...     variable_cost=40.0,
... )

    Documented formulation

    Every variable and constraint is documented. Storage state of charge:

    sock,s,t = sock,s,t−1(1 − δkΔt)+ ηchk ΔtEk pchk,s,t − ΔtηdiskEk pdisk,s,t
    See B-3 and the full formulation →

    Results as pandas

    Dispatch results are returned as pandas Series and DataFrames.

    >>> result.generators.power
